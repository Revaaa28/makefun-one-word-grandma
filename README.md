One-word entry for make.fun's "One Word From Grandma" bounty: `main.py` writes the single word our grandma would text about AI — **robut**, her typo for "robot" — to `entry.txt`. The word was picked by a 12-word proxy-judge round-robin tournament (132 pairwise calls, two independent judge models): it reads as a real grandma texting, warm and a little baffled, funny in one word with no caption, tied directly to robots/AI, and fresh while instantly readable.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```
